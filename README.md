# تطبيق معلمي التكنولوجيا — مديرية التربية والتعليم – يطا

تطبيق ويب (PWA) لسجلات معلمي التكنولوجيا في مديرية التربية والتعليم – يطا.
يعمل على الهاتف وكمبيوتر، ويُثبَّت كأيقونة مستقلة، ويدعم العمل دون اتصال.

> هذا التطبيق هو النسخة الويب الحديثة من تطبيق MIT App Inventor الأصلي
> `techteacher.aia`، ويقرأ ويكتب على **نفس جدول Google Sheets** وبنفس
> بروتوكول الإضافة (GSAI2) — أي أن البيانات متطابقة تماماً.

---

## ✨ مزايا البحث المطوّر

التطبيق الأصلي كان يشترط تطابق «رقم الهوية» و«الاسم» معاً وبطريقة تطابق تام
فقط. محرك البحث هنا يدعم:

| الميزة | مثال |
| --- | --- |
| تطبيع عربي كامل | «أحمد» = «احمد» = «آحمد»، «مصطفى» = «مصطفي» |
| أرقام هندية/عربية | `٨٥٣٩` = `8539` |
| بحث جزئي | «بطش» تجد «أسامة أحمد علي بطش» |
| بادئة الاسم | «ابراه» تجد كل «إبراهيم…» |
| أخطاء إملائية (Fuzzy) | «اسامه» تجد «أسامة»، «دبابسي» تجد «دبابسه» |
| كلمات في حقول مختلفة | «اسامه اعزيز» تجد الاسم + المدرسة معاً |
| أوضاع بحث منفصلة | كل الحقول / الاسم / رقم الهوية / المدرسة / التخصص |
| فلاتر | المؤهل العلمي، المدرسة، التخصص |
| إبراز النتائج | تظليل الجزء المطابق داخل الاسم والهوية |
| عمليات بحث سابقة | شرائح قابلة للنقر أسفل مربع البحث |
| ترتيب ذكي | مطابقة الاسم التامة أولاً، ثم قوة المطابقة |

**تصميم محرك البحث ثلاثي المراحل** (`js/search.js`):

1. **مطابقة مباشرة** داخل الحقل (تام / بادئة / بداية كلمة / جزئي / كل الكلمات).
2. **كلمات موزّعة على حقول السجل** (الاسم هنا والمدرسة هناك).
3. **مطابقة تقريبية** Damerau–Levenshtein بسقف متباعد لمعالجة الأخطاء الإملائية.

مع فحص رخيص مسبق على النص المسطّح، وفهرس بحث يُبنى مرة واحدة عند التحميل.
النتيجة: بحث في **5000 سجل خلال ~25 مللي ثانية** (41 اختباراً ناجحاً).

## 📲 التثبيت كأيقونة على الجهاز

بعد فتح الرابط مرة واحدة:

- **أندرويد (Chrome):** قائمة المتصفح **⋮** ← **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
- **آيفون / آيباد (Safari):** زر **المشاركة** ⬆ ← **«إضافة إلى الشاشة الرئيسية»**.
- **كمبيوتر (Chrome / Edge):** أيقونة **التثبيت** في شريط العنوان، أو زر **«تثبيت التطبيق»** داخل الصفحة.

بعد التثبيت يظهر التطبيق في قائمة برامج الجهاز بالشعار الرسمي لمديرية
التربيّة والتعليم، ويفتح بدون شريط المتصفح، ويعمل دون اتصال (آخر نسخة محفوظة).

## 🔍 المزايا الأخرى

- **قراءة سريعة:** تصدير CSV أولاً (مثل التطبيق الأصلي — التواريخ بصيغة
  `dd/MM/yyyy`)، ثم Apps Script كخيار بديل، ثم نسخة مخزّنة محلياً.
- **الحفظ:** عبر نفس بروتوكول إضافة GSAI2:
  `GET {SCRIPT_URL}?FN=appendRow|writeRow&ID=..&SH=..[&ROW=..]&DATA=<json>`
  — تحديث الصف الموجود عند وجود «رقم» وإلا إضافة صف جديد.
- **Offline:** Service Worker يخزّن الواجهة والبيانات؛ يعمل التطبيق دون إنترنت.
- **مسودات:** يُحفظ ما تكتبه تلقائياً (7 أيام) ويُستعاد عند إغلاق الصفحة بالخطأ.
- **لوحة المفاتيح:** `ArrowUp/Down` للتنقل بين النتائج، `Enter` للفتح، `/` للتركيز على البحث.
- **الوصولية:** اتجاه RTL، دعم القراءة الشاشية، تقليل الحركة، وضع داكن تلقائي.

## 🗂️ بنية المشروع

```
techteacher-pwa/
├── index.html              # الهيكل الرئيسي (RTL/عربي)
├── manifest.webmanifest    # تعريف PWA (الأيقونات، الأسماء، الاختصارات)
├── sw.js                   # Service Worker (عمل دون اتصال)
├── favicon.ico
├── css/app.css             # الواجهة كاملة (responsive + وضع داكن)
├── icons/                  # أيقونات 16–512 + maskable + apple-touch
└── js/
    ├── config.js           # معرّف الجدول، رابط السكربت، خريطة الأعمدة (49)
    ├── search.js           # محرك البحث المطوّر (القلب)
    ├── data.js             # جلب CSV / Apps Script + تحويل الصفوف
    ├── sheets.js           # الحفظ (appendRow / writeRow)
    ├── store.js            # التخزين المحلي (مسودات، بحث سابق، نسخة البيانات)
    └── app.js              # منطق الواجهة والأحداث والتثبيت
```

### إعدادات مهمة (`js/config.js`)

| المتغير | الوصف |
| --- | --- |
| `SHEET_ID` | معرّف جدول Google Sheets |
| `SCRIPT_URL` | رابط تطبيق Apps Script (للقراءة الاحتياطية والكتابة) |
| `CSV_URL` | رابط تصدير CSV (مصدر القراءة الأساسي) |
| `COLUMNS` | خريطة الأسماء ← أرقام الأعمدة (49 عموداً) |
| `REQUIRED_FIELDS` | الحقول المطلوبة في النموذج |
