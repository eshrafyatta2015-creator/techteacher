# خادم بوابة المعلم — Apps Script

هذا الملف (`Code.gs`) هو **طبقة الخادم** التي تُنفّذ الدخول والصلاحيات على
خادم Google (وليس داخل الواجهة فقط). لا علاقة له بالسكربت القديم (GSAI2)
ولا يغيّر فيه شيئاً.

## ما يوفّره

| الوظيفة | الوصف |
| --- | --- |
| `listTeachers` | أسماء المعلمين لقائمة الدخول (لا يعيد أي بيانات أخرى) |
| `login` | مطابقة الاسم + رقم الهوية على الخادم، وإنشاء الحساب تلقائياً |
| `validate` / `logout` | جلسات مؤمّنة برمز عشوائي (12 ساعة) |
| `getMyData` | بيانات **صاحب الجلسة فقط** — مرفوض لبيانات غيره |
| `updateMyData` | تعديل حقول مسموحة فقط + تحقق + منع تكرار + سجل تدقيق |
| `changePassword` | تغيير كلمة المرور بعد إثبات الحالية |
| `adminAccounts` / `adminReset` / `adminStatus` / `adminAudit` | إدارة المسؤول |
| تشفير | PBKDF2-SHA256 · ملح خاص لكل حساب · 120,000 تكرار |

## خطوات النشر (مرة واحدة)

1. افتح [script.google.com](https://script.google.com) بحسابك ← **مشروع جديد**
   (Project name: `بوابة المعلم`).
2. احذف محتوى `Code.gs` الافتراضي، والصق محتوى هذا الملف كاملاً.
3. شغّل الدالة `setup()` من القائمة أعلاه ← موافقة على الصلاحيات
   (ينشئ ورقتَي `Accounts` و`AuditLog` في نفس ملف الجدول — **إضافة فقط**،
   وورقة `Sheet1` وبياناتها لا تُمسّ).
4. شغّل `createAdminFromEditor('اسمك', 'رقم هويتك', 'كلمةمرورقوية6+')`
   لإنشاء حساب المسؤول (مرة واحدة فقط).
5. **Deploy → New deployment → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - انسخ رابط الـ Web App (ينتهي بـ `/exec`).
6. الصق الرابط في `techteacher-pwa/js/config.js` داخل:
   ```js
   AUTH_SCRIPT_URL: 'https://script.google.com/macros/s/.../exec',
   ```
7. افتح `login.html` وسجّل الدخول بحساب المسؤول للتأكد، ثم سجّل دخول
   معلم بأسمائه ورقم هويته.

## ملاحظات أمنية

- كلمة المرور الافتراضية = رقم الهوية، ومخزّنة **مجزّأة** (PBKDF2+ملف) —
  لا تظهر كنص مكشوف في أي مكان.
- أول دخول يفرض تغيير كلمة المرور (`MustChangePassword=TRUE`).
- بعد 5 محاولات خاطئة يُعلَّق الدخول 15 دقيقة تلقائياً.
- كل عملية (دخول، تعديل، إعادة تعيين) تُسجَّل في ورقة `AuditLog`.
- بيانات الأداء/الزيارات/التقارير تُضاف لاحقاً كورق جديدة — لا تُعدَّل
  ورقة `Sheet1` ولا أعمدتها الـ49 القائمة.

## إعادة النشر بعد أي تعديل للـ Code.gs

**Deploy → Manage deployments → ✏️ (تعديل) → Version: New version → Deploy**
(لا تنسخ الرابط القديم — يبقى كما هو).
